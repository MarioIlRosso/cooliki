# Definition
Sets are a group of unordered, distinct objects.

The group in which the objects are contained is called a "Set".
The objects are called the "Elements".
## Examples
### Basic Set
Let's define set $A$
$$A = \{1, 2, 3, 4, 5\}$$
Set $A$ contains numbers $1..5$.
### Distinct Objects
$$A = \{1, 2, 2, 3, 4, 5\}$$
Set $A$ contains numbers $1..5$, but has two $2$'s.

This means that:
$$A = \{1, 2, 3, 4, 5\}$$
### Ordering
$$A = \{5, 4, 2, 3, 1\}$$
Ordering in sets doesn't matter.
$$
A = \{5, 4, 2, 3, 1\}
A = \{1, 2, 3, 4, 5\}
$$
## Cardinality
A set's Cardinality is the number of elements the set contains.

The cardinality of a set is written as two `|` surrounding the set.

### Examples
$$A = \{1, 2, 3\}$$
$$|A| = 3$$
Note that like we said, sets can't have duplicates, so cardinality only counts the amount of *unique* elements.
